Git

  • git init — инициализирует новый локальный репозиторий в текущей папке.
  • git clone url — копирует существующий удаленный репозиторий на компьютер.
  • git status — показывает измененные, новые и отслеживаемые файлы.
  • git add имя_файла — добавляет изменения в индекс .
  • git commit -m "сообщение" — сохраняет проиндексированные изменения и создает снимок истории.
